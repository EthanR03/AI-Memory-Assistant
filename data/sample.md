# Sample Memory

This is a sample note for the memory assistant. You can delete it once
you have your own files in this folder.

Project kickoff was on March 3rd. The goal is to build a retrieval-based
memory assistant that can answer questions about my notes. The first
milestone is the ingestion pipeline: load files, chunk them, embed the
chunks, and store them in a vector database.

My favourite test query for later: "What is the goal of the project?"
